# Complaint Classification Skill

## Skill Name
ComplaintCategoryIdentification

## Description
This skill processes unstructured complaint text and categorizes it
into a small, well‑defined set of complaint domains.

## Supported Categories
- Infrastructure
- Utilities
- Sanitation
- Governance

## Skill Characteristics
- Uses structured prompt design
- Produces deterministic outputs
- Easily extendable for additional categories
- Suitable for integration into ticketing or civic systems

## Used In
UC‑0a: Complaint Classifier
